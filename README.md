# Explore With Me

**Explore With Me** — это REST-сервис для публикации и поиска событий.

Сервис позволяет пользователям:

- 🔍 искать интересные события;
- 📝 создавать собственные события;
- 🤝 отправлять заявки на участие в мероприятиях.

Администратор системы может:

- ✅ модерировать события;
- 📋 контролировать публикуемый контент.

## Основные возможности

- Публикация событий.
- Поиск событий по различным критериям.
- Управление заявками на участие.
- Модерация событий администратором.
